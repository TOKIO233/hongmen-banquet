# 重生鸿门宴

范增视角的互动剧情游戏，包含本地游戏、参考素材库和飞书妙搭适配工程。

## 本地运行

进入 `游戏源码` 目录，运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

在浏览器打开 http://127.0.0.1:8765/。macOS 也可以双击根目录的 `启动游戏.command`。游戏逻辑、剧情及配音配置在 `游戏源码/dist`，详见 `游戏源码/使用说明.md`。

## 目录

- `游戏源码/`：当前可运行的游戏、立绘、剧情和已接入的配音。
- `游戏资源库/`：项目参考素材与分类资源，保留原文件。
- `妙搭部署/`：飞书妙搭项目源码。这里的资源映射指向原妙搭应用存储；迁移到其他妙搭应用时需重新上传资源并更新映射。本仓库不包含本地凭据和应用绑定配置。

开发时请优先修改 `游戏源码/` 并在本地验证。妙搭适配代码是发布时的一份副本，更新游戏后需要同步并验证后再发布。不要提交 `.env.local`、密钥、依赖目录或个人数据。
