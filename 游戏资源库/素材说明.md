# 游戏资源库说明

素材来自桌面“重生鸿门宴”文件夹和飞书文档（版本 806）：https://ycnezwebj31p.feishu.cn/docx/ERZIdDWkwozV0Dxsh7TcL3h7nld 。桌面原件保留；此处为整理副本。

- 人物：按角色分文件夹；全身像、半身特写、三视图和表情九宫格统一命名；动作立绘、文档参考及桌面不同版本另行保留。三视图部分包含额外特写。
- 声音：区分人物音色和剧情配音。它们从文档下载，尚未接入游戏或进行字幕对时。
- 道具、场景、界面 UI 和参考素材按用途分类。文档标记废弃的场景放在“场景/废弃版本”。
- 文档图片的自动描述中出现过角色误标；以文档章节及画面比对结果归档。桌面无名称的九张图依次为张良、项庄、项伯的三视图、半身及表情。
- 樊哙三视图和表情九宫格为本次用内置图片生成工具参照桌面全身像补制，文件名带 AI生成；其余为原始资源。补图为静态图片，尚未制作动画或接入游戏。
- “桌面素材对应记录.json”记录原文件及校验值；“飞书素材下载记录.json”记录文档内素材下载结果。
